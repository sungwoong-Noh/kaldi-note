## 어떻게 동작 — 인수 조건

> 각 조건은 리터럴 값을 쓴다. "적절히", "빠르게", "잘 동작한다" 같은 표현은 금지다.
> 경계값은 각각 별도 조건으로 나눈다.
> ID는 한 번 부여하면 바꾸지 않는다. 테스트가 이 ID로 스펙을 역참조한다.

### 정상 동작

#### AC-<ID>-01 · <한 줄 요약>

- **Given** <전제 상태. 구체적인 값으로>
- **When** <행위>
- **Then** <결과. 정확한 값으로>
- **검증** <단위 테스트 `XxxTest` / 통합 테스트 `XxxTest` / API 테스트 `XxxControllerTest`>

#### AC-<ID>-02 · <한 줄 요약>

- **Given** 
- **When** 
- **Then** 
- **검증**
