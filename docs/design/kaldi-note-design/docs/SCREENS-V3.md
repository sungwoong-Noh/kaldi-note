## 공통 규칙에서 기존 문서와 어긋난 것

1. **탭 3번째 이름** — 요청문은 「기록」, `DECISIONS.md`는 「내 잔」. DECISIONS가 우선이라 **「내 잔」**으로 그렸습니다.
2. **에러 색** — 새 색을 만들지 않고 기존 `signal-record oklch(0.55 0.16 30)`를 검증 에러에 사용.

공개 범위(PRIVATE / FRIENDS / PUBLIC) · 온도(HOT / ICE) · 배전도(3단계) · 스텝 종류(배출 포함) · 붓는 방식(가장자리 포함) · 교반(젓기 포함) · 분쇄도 단위(마이크론 포함)는 `DECISIONS.md` 및 정정된 요청문과 일치합니다.
