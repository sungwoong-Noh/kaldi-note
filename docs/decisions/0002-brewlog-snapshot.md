# 0002. BrewLog는 레시피 값을 스냅샷으로 복사해 갖는다

## 맥락

`BrewLog`가 `Recipe`를 FK로만 참조하면 저장 공간을 아낄 수 있다. 하지만 레시피의 `dose_g`를
15g에서 16g으로 수정하면, FK 참조만으로는 과거 기록도 16g으로 읽힌다.

## 결정

**`BrewLog`는 기록 시점의 레시피 값을 스냅샷으로 복사해 저장한다.** FK(`recipeId`)는
"어느 레시피에서 나왔는가"를 가리키는 용도로만 남기고, 값 자체는 스냅샷이 정본이다.

## 결과

- 레시피를 수정해도 과거 기록은 그 시점 값 그대로 남는다 — 과거가 조작되지 않는다.
- 스키마가 중복을 갖는다(레시피 값 필드가 `Recipe`와 `BrewLog` 양쪽에 있다). 의도된 중복이다.
- `recipe_snapshot`(JSONB, `docs/specs/2026-09-20-recipe-v2-data-model.md`에서 도입)이 이
  결정의 실제 구현이다.
