메뉴는 이렇게 둡니다

화면이 16개면 CTA 하나로는 이동할 수 없습니다. 하단 탭 4개 + 기록 버튼 구조를 권합니다 — 목적지는 홈·레시피·기록·더보기 네 개뿐이고, 「기록하기」는 탭이 아니라 홈과 각 목록 화면의 CTA로 남깁니다. 텍스트 라벨만 쓰고 아이콘은 두지 않습니다(이 브랜드는 선·수치·여백으로 말합니다).

Rules
높이 58px + 하단 세이프에어리어. 상단 1px border, 배경 paper. 각 탭 히트 영역 44px 이상.
활성 = 13px 600 ink + 18×2 밑줄. 비활성 = 13px 400 ink-3. 아이콘·배지·점 없음.
탭이 있는 화면: 홈 · 레시피 목록 · 기록 목록 · 더보기. 없는 화면: 상세 · 작성/편집 · 타이머 · 로그인 · 오프라인(뒤로/닫기만).
이미 있는 탭을 다시 누르면 목록 맨 위로, 길게 누르면 마지막 위치 유지.
CTA는 어디로
「이 레시피로 내렸다」·「새 레시피」는 탭 바 위에 붙는 화면별 액션으로 남깁니다. 탭 바에 + 버튼을 끼워 넣지 않습니다 — 기록은 항상 레시피를 고른 뒤에 시작되기 때문입니다.
프로필 /u/[id]과 분쇄도 환산기는 탭이 아니라 더보기·피드에서 들어갑니다.
