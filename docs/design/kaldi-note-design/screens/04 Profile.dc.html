결정할 것 · 추천값
Q1. 맞팔로우일 때 보여줄 것
추천: FRIENDS 레시피 목록 먼저, 최근 잔은 두 번째 탭. 초대받은 사람이 가장 먼저 원하는 건 “이 사람은 뭘 내려 먹지?”입니다. API 2개 필요(레시피 by user, 잔 by user).
Q2. 둘 다 아님 문구
추천: 「서로 팔로우하면 레시피와 기록을 함께 볼 수 있습니다.」를 서버 문자열로 추가. 초대 링크 첫 화면이 비어 보이지 않게.
Q3. 상대만 팔로우일 때 버튼 라벨
추천: 「맞팔로우하기」. 동작은 팔로우와 같지만 결과(서로 보임)가 바로 드러납니다.
Q4. 팔로워·팔로잉 수
반영됨 — 화면에서 뺐습니다. 1차에는 빼기. 친구끼리 쓰는 앱이라 숫자 경쟁 신호가 됩니다. 웹 좌측의 빈 공간은 레시피 수(API 없음)로 대체 가능.
Q5. 팔로우 취소 확인
추천: 맞팔로우 상태에서만 확인 다이얼로그(「취소하면 서로의 기록이 보이지 않습니다.」). 나머지는 즉시.
