정해 주셔야 할 것

01
탭 이름 「기록」 vs 「내 잔」(DECISIONS #1)
추천「기록」
홈이 「오늘」로 바뀌고 레시피가 기록에서 나오게 되면서 「기록하기」(동사)와 「기록」(탭)이 같은 대상을 가리킵니다. 「잔」은 셀 때만(「이번 주 4잔」). 채택하면 DECISIONS #1을 고쳐야 합니다.
02
말투 — 「기록했어요」(해요체) vs README 보이스 「저장했습니다」
추천질문 · 버튼 · 완료만 해요체, 기록 · 통계 · 비교 문장은 합니다체
행동을 권하는 자리와 사실을 돌려주는 자리를 말투로 나누면 「판단하지 않는다」 원칙이 유지됩니다. README 보이스 표에 한 줄 추가 필요.
03
「이대로 기록」이 ①을 건너뛰고 ②에서 시작할지
추천건너뜀
탭 3번 목표가 이 경로에서만 성립합니다. 카드에서 이미 값을 보고 눌렀으므로 다시 묻는 것은 중복입니다.
04
시트 뒤 스크림 색
추천ink 32% 알파(다크는 0.1 명도 55%)
README에 없는 값입니다. 새 색이 아니라 ink 토큰의 투명도라 토큰 사전에 「scrim」으로 추가를 제안합니다.
05
완료 체크 아이콘 예외
추천허용(이 1개만)
텍스트만으로는 「끝났다」가 한눈에 안 들어옵니다. 1.5px 선 · 단색 · 그림자 없음으로 로고 심볼과 같은 선 문법입니다.
06
로스팅 날짜(daysOffRoast · 디개싱 상태)를 어디서 받을지
추천「자세히」 안에 「로스팅 날짜(선택)」 칸, 같은 원두면 지난 값 채움
봉투 등록 단계를 없애면 roastedAt을 넣을 곳이 사라집니다. 비워 두면 상세에서 「로스팅 후 N일」 줄을 숨깁니다. 「API 없음」 아님 — 기존 필드 재배치.
07
「직접 입력」한 원두 이름을 「최근 고른 원두」에 남길지
추천남김
카탈로그에 없는 원두를 두 번째 기록할 때 다시 타이핑하지 않도록. 카탈로그 연결은 나중에 상세에서.
08
「이번 주」의 시작 요일
추천월요일
기록 달력의 주 시작과 맞춥니다.
09
별점 0.5 입력
추천별 왼쪽 절반 탭 = .5, 별 위를 끌면 0.5 단위
rating 0.5~5.0 범위를 버튼 10개 없이 담는 가장 짧은 방법입니다. 스크린리더는 슬라이더(step 0.5)로 노출.
10
기록 중 시트를 닫을 때
