결정할 것 · 추천값
Q1. 영점 보정 입력 위치
추천: 이 화면에서 직접 입력(±0.5 스테퍼) + 환산기에 역보정 도우미를 나중에. 직접 입력은 구현이 단순하고 값의 의미가 명확합니다. 역보정(「내 값이 이 정도였다」)은 입문자에게 좋지만 환산 공식에 의존하므로 2차로.
Q2. 등록 시 기본 지정
추천: 첫 그라인더는 자동 기본. 두 번째부터는 등록 후 상세에서 토글.
Q3. 같은 모델 중복 등록
추천: 허용(집/회사 같은 모델 2대). 별칭 없이 중복이면 저장 시 「별칭을 붙이면 구분하기 쉽습니다」 안내만.
Q4. µm/클릭이 없는 모델
추천: 「—」로 두고 환산 불가 배지. 대표 수치 자리에는 범위(0–10)를 대신 표시.
Q5. 목록에 없는 모델 요청
추천: 1차는 안내 문구만. 요청 폼은 운영 부담이 생기므로 사용자 수 확인 후.
