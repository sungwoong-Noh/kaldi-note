지연 님 프로필 보기
웹에서 달라지는 점
셀 = 박스, 점 + 한 줄
셀이 커진 만큼 날짜 옆에 점을 두고 아래 레시피명 11.5px 한 줄. 2건 이상이면 "외 N건". 2줄 이상 쌓지 않습니다.
그리드 선
1px oklch(0.93 0.008 80) 격자, 상단만 divider-strong. 다른 달 칸은 oklch(0.975 0.006 82)로 비웁니다.
선택 표시
셀 전체에 inset 0 0 0 2px ink + 배경 한 단. 숫자는 24px 원. 오늘이지만 선택 안 됨 = 1px 링만.
우측 컬럼
420px 고정, surface 배경. 모바일의 원장 행 대신 카드로 — 공간이 있으니 태그와 메모까지 함께 보여줍니다. 이 영역만 스크롤.
팔로우 레일
아바타 32px + 이름을 가로 pill로. 선택은 ink 배경 pill(모바일의 링 대신 — 가로 배치라 링이 약합니다).
CTA
상단 바 CTA는 전역, 우측 컬럼 하단 CTA는 선택된 날짜 맥락(「이 날짜로 기록 추가」). 남의 달력에서는 「프로필 보기」로 바뀝니다.
반응형
1100px 미만에서 우측 컬럼이 달력 아래로 내려가 한 컬럼이 됩니다. 760px 미만은 모바일 레이아웃(점만, 셀 44px).
행 수 고정
달이 6주에 걸치면 repeat(6,1fr)로 늘리고 셀 높이를 줄입니다. 그리드 영역 높이는 항상 동일 — 월 전환 시 레이아웃이 튀지 않아야 합니다.
