결정할 것 · 추천값
Q1. 스텝 물 합계 ≠ 총 물량
추천: 경고만, 저장은 허용. 합계 텍스트를 accent로 바꾸고 Observation에 「스텝 물 합계가 총 물량보다 20 g 적습니다.」 실제 추출은 어긋날 수 있어 막으면 불편합니다.
Q2. 스텝 순서 변경
추천: 위/아래 버튼 기본, 웹만 드래그 추가. 모바일은 스크롤과 드래그가 충돌하고 30개 목록에서 정밀하지 않습니다. 순서가 바뀌면 시작 시각은 자동으로 다시 계산할지(Q3).
Q3. 시작 시각 자동 계산
추천: 새 스텝의 시작 = 직전 스텝 시작 + 지속으로 채워 두고 수정 가능. 겹침(시작 < 직전 종료)은 경고만.
Q4. 에러 색
추천: 기존 signal-record oklch(0.55 0.16 30)을 에러에도 씁니다(새 색 없음). 달력 점과 의미가 겹치는 게 싫다면 accent + 굵은 보더로 대체.
Q5. 추정 입도 표시 시점
추천: 저장 전에는 「저장하면 추정 입도가 계산됩니다」, 저장 후 「약 660 µm · 추정치」. 「약」+「추정치」를 둘 다 붙여 확정값처럼 보이지 않게.
