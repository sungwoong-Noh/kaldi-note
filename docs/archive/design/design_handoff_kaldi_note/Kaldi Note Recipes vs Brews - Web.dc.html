레시피는 카드, 기록은 장부

둘이 헷갈리는 건 레이아웃이 같아서입니다. 레시피는 앞으로 반복할 지침이라 골라 보는 카드 그리드로, 기록은 지나간 사실이라 날짜순으로 쌓이는 표로 갈랐습니다. 아래 결정 패널의 용어·포크 흐름부터 확인해 주세요.

결정 01 — 용어
레시피
앞으로 이렇게 내리겠다는 지침. 반복 가능, 날짜 없음, 남과 공유 가능.
한 잔
기록을 세는 말을 「잔」으로 통일합니다. “오늘의 한 잔”, “이번 주 6잔”, 탭 이름은 내 잔.
「기록」은 동사로만 씁니다 — “기록하기”. 명사 자리에는 「잔」. 레시피 화면에서 “기록”, 기록 화면에서 “레시피”가 같은 무게로 나오지 않게 하는 것이 목적입니다.
결정 02 — 포크 대신 담기
「포크」를 버리고 「내 서랍에 담기」로 바꿉니다. 누르면 바로 복제하지 않고 편집 화면으로 한 번 보냅니다 — 내 원두·기구로 고쳐야 쓸 수 있으니, 그 자리가 곧 설명이 됩니다.
1
남의 레시피에서 「내 서랍에 담기」
2
편집 화면 — 상단에 출처 배지가 붙은 채로 열립니다
3
저장하면 내 서랍에 들어가고 지연 님 레시피에서 표시가 남습니다
출처 배지는 목록 카드와 상세 양쪽에 남습니다. 원본이 수정돼도 내 것은 따라가지 않습니다(복제 시점 고정).
결정 03 — 두 개의 레시피 화면
전체가 섞여 뜨는 지금 구조를 둘러보기 / 내 서랍으로 나눕니다. 탭 「레시피」의 기본은 내 서랍이고, 둘러보기는 그 옆 세그먼트입니다.
내 서랍
내가 만든 것 + 담아온 것. 바로 내릴 수 있는 것만.
둘러보기
검색 + 필터(원두량·Hot/Ice·배전도·기구) + 공개 레시피. 마켓처럼 고르는 곳.
결정 04 — 카드 항목 교체
대표 수치는 비율에서 원두량으로 바뀝니다. 고를 때 먼저 묻는 건 “몇 그램 쓰지?”이기 때문입니다.
16 g
원두량 — 대표 수치, mono 24~36px
HOT
Hot / Ice — 채운 칩(HOT은 ink, ICE는 외곽선)
중배전
추천 배전도 — 로스트 도트 + 라벨
비율·온도·시간은 카드에서 빼고 상세로 넘깁니다. 카드에 4개 이상 수치가 들어가면 고르는 데 방해가 됩니다.
