# 0006. 마스터 데이터(품종·가공법·그라인더)는 FK로 정규화한다

## 맥락

품종·가공법·그라인더 모델 같은 값을 문자열 컬럼으로 그냥 저장하면 초기 구현이 빠르다.

## 결정

**전부 별도 테이블로 만들고 FK로 참조한다.** 문자열로 박지 않는다.

## 결과

- "게이샤"와 "Geisha"처럼 표기가 갈리는 중복을 나중에 병합할 방법이 생긴다 — 문자열이었다면
  이미 흩어진 데이터를 수작업으로 고쳐야 한다.
- 신규 마스터 데이터 추가는 시드 마이그레이션(`V3__seed_catalog.sql` 등)으로 관리된다.
- 대가로 마이그레이션 하나가 늘고, 새 값을 추가하려면 시드부터 넣어야 한다.
