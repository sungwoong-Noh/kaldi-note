# 0003. 분쇄도 환산 결과는 언제나 "추정치"다

## 맥락

그라인더 간 분쇄도 환산값을 확정값처럼 보여주면 사용자가 그대로 믿고 쓴다. 하지만 버
형상·입도 분포가 그라인더마다 달라 정확한 등가 변환은 물리적으로 불가능하다.

## 결정

**환산 결과는 UI에서 항상 "추정치"로 표시한다.** 확정값처럼 보이는 화면(단위·배지 없는 숫자만)을
만들지 않는다.

## 결과

- `frontend/CLAUDE.md`의 UI 규칙 1번 — 환산값 옆에 "추정치" 배지와 경고 문구를 항상 붙인다.
- `microns_per_click`이 없는 그라인더는 환산 자체를 거부한다(추측값을 넣지 않는다) —
  `V5__seed_gear.sql`의 원칙과 같다. 값이 없는 것이 틀린 값보다 낫다.
- 마이크론 → 클릭수 역환산(로드맵 M3)도 같은 제약을 그대로 받는다.
