## 방향 전환 (2026-11-14)

1부 성공 기준 「우리 둘이 실제로 매일 쓴다」(ADR 0009)는 그대로다. 그런데 두 사람 모두 쓰다가 손을 놓았다.
커피 한 잔을 기록하려면 레시피를 쓰고, 원두를 3단으로 등록하고, 그라인더를 등록해야 했다.

**흐름을 뒤집는다 — 기록이 입구이고, 레시피는 괜찮았던 기록을 저장한 것이다.**
기록의 필수값은 원두량·물량뿐이다(`docs/decisions/0011-brew-first-minimal-input.md`).
화면은 `docs/design/kaldi-note-design/screens/10 Brew First.dc.html`, 확정 결정은
`docs/design/kaldi-note-design/docs/DECISIONS.md` 1·6절.

## 1부 — 마일스톤

### P1 · 빠른 기록

**완료 정의:** 둘 다 1주 동안 커피를 내린 날 매일 기록했다.

- 지난번과 같을 때 **기록 탭 3번**, 바꿔도 **30초** 안에 저장된다
- 「오늘」 홈 — 큰 「기록하기」 버튼과 지난 기록 카드(시안 A)
- 빠른 기록 시트 — 필수는 원두량·물량, 나머지는 「자세히」(시안 B)
- 「기록」 탭 — 목록 / 달력(시안 F), 탭 바 「오늘 · 기록 · 레시피 · 더보기」(시안 G)
- 백엔드: 기록 생성의 필수값 축소, 원두 이름 직접 입력
- **원두 검색 API + 사용자 원두 상세(11 Beans)** — 이름 · 로스터 검색과 숨김 제외, 원두 상세의 내 기록 요약. 스펙: 「원두 상세」 — 인터뷰 후 작성(이슈 생성 대기)
- 스펙: 「빠른 기록(오늘 홈 · 빠른 기록 · 기록 탭)」 — 인터뷰 후 작성(#202)

### P2 · 레시피는 기록에서

**완료 정의:** 2주 동안 새로 생긴 레시피의 대부분이 기록에서 「레시피로 저장」으로 만들어졌다.

- 기록 상세의 「레시피로 저장」(시안 D)
- 4칸 레시피 — 이름 · 원두량 · 물량 · 물 온도, 나머지는 「자세히」(시안 E). 지금 03 레시피 작성을 대체한다
- 레시피 상세의 「이걸로 내리기」 → 그 값이 채워진 빠른 기록

### P3 · 타이머

**완료 정의:** 기록의 절반 이상이 타이머를 거쳐 저장됐다.

- 스텝 안내 · 화면 꺼짐 방지 · 끝나면 그대로 기록
- **시작 전에 PWA 실기기 테스트** — 화면 꺼짐 방지(Wake Lock)·소리·백그라운드 동작을 두 사람 폰에서 확인
- 이슈: #144

### P4 · 서비스 껍데기 + 지인 베타

**완료 정의:** 지인 2명 이상이 주 3회 이상 기록한다.

- 앱 아이콘 · 스플래시 · 랜딩 · 약관 · 피드백 창구 · 온보딩
- 운영 `.env`의 테스트 로그인 시크릿 제거(#151)

## 운영 규칙

- **각 마일스톤 끝에 1주 실사용 + 불편 목록.** 불편 목록은 이슈로 만들고, 다음 마일스톤 시작 전에 무엇을 넣을지 정한다
- **동시에 진행하는 마일스톤은 1개.** 끝나기 전에 다음 마일스톤의 인터뷰를 시작하지 않는다
- 마일스톤이 끝나면 이 문서의 「진행 현황」을 「완료 (날짜, PR 번호)」로 바꾼다
- 순서를 바꾸거나 항목을 추가하려면 이 문서를 먼저 고친다
