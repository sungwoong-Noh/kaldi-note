# 0004. TDS 없이도 앱이 온전히 동작해야 한다

## 맥락

추출 수율(EY)을 계산하려면 TDS(굴절계 측정값)가 필요하다. 하지만 리프랙토미터를 가진 사용자가
드물다 — 없는 게 기본 상황이다.

## 결정

**TDS는 선택 입력이다.** TDS가 없어도 브루 비율 계산과 기록 저장은 정상 동작해야 하고, 입력을
강제하지 않는다.

## 결과

- TDS가 없으면 추출 수율·SCA 차트 영역을 숨기고 브루 비율과 관능 평가만 보여준다
  (`frontend/CLAUDE.md` UI 규칙 2번).
- 백엔드 응답 스키마에서 TDS·EY 관련 필드는 전부 nullable이다.
- 회귀 테스트로 고정: "TDS가 없어도 브루 비율은 계산되고 응답이 정상이다"(`backend/CLAUDE.md`).
