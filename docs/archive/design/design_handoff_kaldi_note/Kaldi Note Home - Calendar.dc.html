Selected / today

날짜를 누르면 달력 아래 리스트가 그 날짜로 바뀝니다. 기록이 1건이면 상세로 바로 보내지 않고 리스트에 1행으로 둡니다(일관성).
Follow rail
아바타 50px, 가로 스크롤, 첫 칸은 항상 「나」. 선택 = 2px ink 링 + 라벨 600. 한 번에 한 사람만 선택합니다(겹쳐 보기 없음 — 누구의 기록인지 모호해집니다).
맞팔로우가 아닌 사람은 레일에 나타나지 않습니다. 남의 달력에서는 CTA가 secondary 「이 레시피로 내리기」로 바뀝니다.
