06 — Voice

말투

이렇게
“오늘 기록을 저장했습니다.”
이렇게 말고
“기록 저장 완료! 잘하셨어요 ☕”
이렇게
“아직 기록이 없습니다. 첫 잔부터 남겨보세요.”
이렇게 말고
“텅 비었네요! 어서 커피를 내려주세요~”

담백한 존댓말, 감탄사·이모지 없음, 평가하지 않기. 사용자의 커피가 맛있었는지 앱이 판단하지 않고 사실과 수치만 돌려줍니다. 제안은 명령이 아닌 관찰로: “지난 세 번 모두 92°C였습니다.”
