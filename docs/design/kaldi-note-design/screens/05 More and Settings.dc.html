결정할 것 · 추천값
Q1. 이메일 없을 때
추천: 행을 숨기지 않고 「등록된 이메일 없음 · 카카오 로그인」처럼 로그인 수단을 함께. 비어 있는 이유가 보입니다. 로그인 수단 필드가 API에 있는지 확인 필요.
Q2. 로그아웃 확인
추천: 확인 없음. 되돌리기 비용이 낮고(다시 로그인), 링크형 텍스트로 이미 약하게 두었습니다.
Q3. 「내 기구 관리」 보조 문구
추천: 「그라인더 N대 · 기본 ○○」. 목록 API 한 번이면 됩니다 — 없으면 보조 문구 생략.
Q4. 다크 모드 3상태
추천: 지금은 토글(켜기/끄기) 유지. 「시스템 따라가기」가 필요하면 세그먼티드 3칸으로 교체.
